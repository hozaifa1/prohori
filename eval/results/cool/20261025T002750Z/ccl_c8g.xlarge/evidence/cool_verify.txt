## COOL SDK: Performance Benchmarking Manual

This guide explains how to run the performance tests of the ***Optimized COOL Build***.



### Test Suite Description
The suite contains 3 standardized tests designed to stress CPU/SIMD pipelines:
1.  ***Augmentation:*** (Rotate, Resize 2x, MedianBlur, Float Conv, GaussianBlur)
2.  ***Analysis:*** (CLAHE, Hist, HoughCircles, FindContours)
3.  ***Video:*** (MJPG Transcoding Read/Write)


### Performance Results

Below are the benchmark results comparing the optimized `COOL` build (OpenCV 5.1.0) against the standard tag build (OpenCV 5.0.0) on AWS Graviton (aarch64). For Python, the comparison is against the standard `pip install opencv-python` (OpenCV 5.0.0) wheel; for C++, against a local unoptimized build from the same 5.0.0 tag (pip does not ship a C++ SDK).

#### Python Performance ( Python 3.12 )
| Test Case | pip install (OpenCV 5.0.0) | Optimized (COOL) |
| :--- | :--- | :--- |
| **Augmentation** | 17.69 ms | **11.84 ms** |
| **Analysis** | 1774.04 ms | **1658.69 ms** |
| **Video Transcode** | 116.34 ms | **102.15 ms** |

#### C++ Performance
| Test Case | Standard (OpenCV 5.0.0) | Optimized (COOL) |
| :--- | :--- | :--- |
| **Augmentation** | 15.29 ms | **14.48 ms** |
| **Analysis** | 1657.22 ms | **1643.77 ms** |
| **Video Transcode** | 116.28 ms | **80.63 ms** |

### Part 1: Python Benchmarking

#### Testing the Optimized Build (COOL)
1.  ***Activate the Environment:***

    `
    source /opt/cool/venvs/python_3.12/bin/activate
    `
2.  ***Verify Optimization:***

    `
    python3 -c "import cv2; print(f'Active OpenCV: {cv2.__version__} from {cv2.__file__}')"
    `
3.  ***Run Test (Example):***

    `
    python3 /opt/cool/samples/python/test_augmentation.py 
        --input /opt/cool/samples/data/lena.jpg 
    `

### Part 2: C++ Benchmarking

#### A. Testing the Optimized Build (COOL)

    `

    `sudo ./build.sh
    `
2.  ***Run Test:***

    `
    /opt/cool/samples/cpp/build/test_aug /opt/cool/samples/data/lena.jpg 
    `
